# Guess-the-Number---Edublocks-using-HTML
Guess the Number is an interactive number guessing game built using EduBlocks, a block-based visual coding platform that uses HTML, CSS, and JavaScript. The game generates a random secret number between 1 and 100 and challenges the player to guess it correctly.

## 🎮 How to Play

1. The computer picks a random number between **1 and 100**
2. Type your guess in the input box
3. Click **Submit Guess**
4. The game tells you if your guess is **Too High** or **Too Low**
5. Keep guessing until you find the correct number!
6. A **victory sound** plays when you guess correctly 🎵

## ✨ Features

- Random number generation between 1 and 100
- Attempt counter to track your guesses
- Too High / Too Low feedback messages
- 🎉 Victory celebration with sound effect
- Play Again button to restart the game

## 🛠️ Built With
- Edu block-based coding platform
- HTML
- CSS
- JavaScript (Web Audio API for sound)
